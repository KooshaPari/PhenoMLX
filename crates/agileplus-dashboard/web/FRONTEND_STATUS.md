# Dashboard Web Scaffold

This directory is preserved as historical React/Vite component work. It is not
the active AgilePlus dashboard frontend and must not be advertised as runnable
until it has a package manifest, lockfile, TypeScript config, app entrypoints,
and passing build/test gates.

The active local dashboard is the Rust/Axum/Askama surface in
`crates/agileplus-dashboard`.
