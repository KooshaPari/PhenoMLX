# VS-01 completion gate

VS-01 implementation complete requires all blocking machine-readable trace rows satisfied and schema-valid profile/qualification receipts.

Not equivalent to PhenoMLX CVP or existence.

## Required bundle
- RequestedProfile + RealizedProfile for two real engines/common exact model;
- engine/package/build versions and hardware identity;
- matched QualificationWorkload;
- quality oracle results;
- latency/token/resource evidence;
- explicit unsupported/not-observable fields;
- lifecycle evidence for applicable cancel/unload/restart/stream behavior;
- SupportEnvelope derived from verified qualification, not static capabilities.

## Automatic red
cross-hardware winner; different model/tokenizer; unknown field fabricated; static BackendCapabilities treated as verified; quality oracle absent; warm/cold mismatch hidden; custom extension compared against weak/non-idiomatic baseline; setup failure called pass.

## Acceptance
Independent reviewer can reproduce/invalidate the comparison from raw receipts.
